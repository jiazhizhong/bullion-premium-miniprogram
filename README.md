# 金银投资小程序

基于设计稿实现的微信小程序，提供贵金属投资相关的功能。
![扫码查看](images/qr.jpeg)

## 功能特性

### 主要页面
1. **首页** - 实时行情、热门产品、价格走势
2. **行情页** - 详细行情信息
3. **资产页** - 资产管理和统计
4. **我的页** - 个人中心和工具入口

### 功能模块
- ✅ 实时行情展示（黄金、白银）
- ✅ 价格换算（国际价格转人民币）
- ✅ 溢价计算器
- ✅ 资产管理（添加、查看、删除）
- ✅ 资产统计（持仓数量、价值、盈亏）

## 使用说明

### 1. 配置小程序

1. 打开微信开发者工具
2. 导入项目，选择 `miniprogram` 目录
3. 在 `project.config.json` 中配置你的 AppID

### 2. 添加图标资源

需要在 `images` 目录下添加以下图标文件：

- `tab-home.png` / `tab-home-active.png` - 首页图标

- `tab-assets.png` / `tab-assets-active.png` - 资产图标

### 3. 数据说明

#### 全局数据
- `marketData`: 实时行情数据
- `exchangeRate`: 汇率（默认 7.2）
- `assets`: 用户资产数据（存储在本地）

#### 数据存储
- 资产数据使用 `wx.setStorageSync` 存储在本地
- 行情数据在 `app.js` 中初始化，可连接真实API

### 4. 功能说明

#### 价格换算
- 输入国际金价/银价（美元/盎司）
- 自动计算人民币价格（元/克）
- 公式：`人民币价格 = (美元价格 × 汇率) / 31.1035`

#### 溢价计算
- 选择金属类型（黄金/白银）
- 输入基准价格和买入价格
- 自动计算溢价金额、溢价率、溢价等级
- 溢价等级：
  - 0-5%: 正常溢价（绿色）
  - 5-10%: 偏高溢价（黄色）
  - >10%: 高溢价（红色）

#### 资产管理
- 添加资产：输入价格、克数、渠道、时间
- 查看资产：显示持仓数量、价值、均价、盈亏
- 删除资产：长按或点击删除按钮

## 注意事项

1. **图标资源**: 需要添加所有图标文件，否则部分页面可能显示异常
2. **AppID**: 需要在 `project.config.json` 中配置你的小程序 AppID
3. **数据持久化**: 资产数据存储在本地，清除缓存会丢失数据
4. **样式单位**: 使用 `rpx` 单位，适配不同屏幕尺寸
